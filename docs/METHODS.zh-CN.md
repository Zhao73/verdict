# Verdict 独家方法

[English](METHODS.md)

在 Verdict 里，模型负责研究、辩论和做决策，**计算全部交给代码**。一共有七种方法，全部由代码按固定规则计算：
- 三种在模型动笔之前算好，让研究台拿自己的论点去对照；
- 四种在结论出来之后算，用来检验结论。

七种方法最后汇总成 **Verdict 评分**。每种方法要么给出数字，要么说明为什么不适用。不适用算作数据缺口，不会影响结论的方向。

| | 方法 | 回答的问题 | 引用编号 |
|---|---|---|---|
| 之前 | 价格隐含的增长 | 要让现价合理，公司需要做到什么？ | `method:implied_growth` |
| 之前 | 期权隐含波动 | 期权市场预期股价会波动多大？ | `method:implied_range` |
| 之前 | 走势状态 | 趋势是在帮你的论点还是在跟它作对？现在走势平稳还是剧烈？ | `method:regime` |
| 之后 | 触及概率 | 股价到底有多大可能走到每个价位区间？ | |
| 之后 | 收益风险 | 按不同情景加权后，这个估值区间能带来多少回报？ | |
| 之后 | 证据天平 | 所有有出处的证据加权后偏向哪一边？ | |
| 之后 | 一致性检查 | 评级、估值、收益风险和证据的方向一致吗？ | |

## 模型动笔之前

### 1. 价格隐含的增长（反向 DCF）

大多数估值讨论问的是"这家公司值多少钱"。这个方法反过来问："现价已经假设了什么？"研究台再拿证据去检验这个假设。

1. 企业价值 = 市值 − 净现金。
2. 用两阶段现金流折现模型：
   - 过去 12 个月的自由现金流（为负时改用净利润）每年增长 *g*，持续 10 年；
   - 之后每年增长 2.5%，一直持续下去；
   - 折现率统一取 9%。
3. 求出让模型结果正好等于企业价值的 *g*（二分法，范围每年 −50% 到 +100%）。
4. 拿 *g* 和公司过去 3 年的收入复合增长率比，**差距** = *g* − 历史增速：
   - 高于 +5 个百分点：*预期偏高*
   - 低于 −5 个百分点：*预期偏低*
   - 其余：*预期合理*

以下情况不适用：
- 没有财报数据（免 Key 快照只有美股的 SEC XBRL 数据）；
- 现金流和利润都为负（现价押注的是将来扭亏）；
- 净现金超过市值。

### 2. 期权隐含波动

- 一个标准差的波动幅度 = 平值隐含波动率 × √(天数 / 365)。
- 波动区间 = 价格 × e^(±波动幅度)，分别算最近一个到期日和最接近 30 天的到期日。
- 隐含波动率 ÷ 近 30 日实际波动率，用来判断期权定价的波动是否大于近期实际：
  - 大于 1.25：期权已经在为某个事件定价
  - 小于 0.8：市场偏乐观、定价偏低
  - 其余：定价合理

### 3. 走势状态

- **趋势**：
  - 价格在 200 日均线之上，且 50 日均线也在 200 日均线之上：*上升趋势*
  - 两者都在下方：*下降趋势*
  - 其余：*趋势转折*
- **波动**：近 30 日实际波动率 ÷ 近 90 日实际波动率：
  - 大于 1.25：*波动剧烈*
  - 小于 0.8：*平稳*
  - 其余：*波动正常*

九种组合各带一条给研究台的择时提示，例如"无序下跌：既有恐慌抛售的风险，也有机会，分批建仓"。

## 结论出来之后

### 4. 触及概率

一个在持有期内根本到不了的价位，算不上计划。Verdict 计算股价在 3 个月内触及每个价位区间的概率。模型假设价格按无漂移的对数正态随机游走，用反射原理计算：

```
P(触及价位 B) = 2 · Φ( −|ln(B / S)| / (σ · √T) )，T = 0.25 年
```

σ 取最接近 60 天的平值隐含波动率；没有期权数据时改用实际波动率。价格已经在其中的区间记为 100%。

### 5. 收益风险

情景加权价值 = 25% 悲观 + 50% 基准 + 25% 乐观。Verdict 据此给出：
- 期望回报；
- 到乐观价值的上行空间，以及到悲观价值的下行空间；
- **收益/风险** = 上行空间 ÷ |下行空间|。

判断标准：
- *有利*：期望回报高于 +5%，且收益/风险不低于 2
- *不利*：期望回报低于 −5%，或收益/风险低于 0.8
- *均衡*：其余情况

### 6. 证据天平

每个研究台的每一条有出处的发现都算一票：看多 +1，看空 −1，中性或多空交织 0。每一票按它最好的那个来源的质量加权：

| 来源 | 权重 |
|---|---|
| 交易所和监管机构公告、公司投资者关系页面、代码直接抓取的数据 | 1.0 |
| Verdict 独家方法和方法筛选 | 0.9 |
| 主流财经媒体（路透、彭博、FT、WSJ、日经、财新……） | 0.8 |
| 新闻标题和其他网页 | 0.6 |

同时引用两个及以上来源的发现，权重再乘以 1.15。

**天平值** = Σ 票 × 权重 ÷ Σ 权重，范围在 −1 到 +1 之间。高于 +0.15 为*偏多*，低于 −0.15 为*偏空*。每个研究台也单独计算天平值；任意两个研究台相差 1 或以上，记为*各研究台分歧明显*。

### 7. 一致性检查

代码逐条检查结论里有没有自相矛盾：
- 评级与证据天平的方向；
- 评级与基准估值（买入或增持时现价却高于基准价值，卖出或减持时现价却低于基准价值）；
- 评级与收益风险；
- 有 3 个以上数据缺口或有任务失败时，仍给出高置信度；
- 各研究台分歧明显。

检查结果不会改动评级，只告诉读者：这个结论在哪里还需要说清楚。

## Verdict 评分

| 组成 | 权重 | 0–100 分怎么算 |
|---|---|---|
| 价值 | 35% | 期望回报 −30% 记 0 分，+30% 记 100 分 |
| 证据 | 30% | 50 + 50 × 证据天平值 |
| 基本面 | 20% | 非技术类方法筛选的平均分 |
| 走势 | 15% | 上升 75 · 转折 50 · 下降 25；平稳 +5，剧烈 −10 |

缺少的组成部分会被去掉，剩下的权重重新按比例分配；可用的组成部分少于两项时不出评分。分档：70 以上为强 · 55 以上偏强 · 45 以上中性 · 30 以上偏弱 · 30 以下为弱。

评分用来交叉检验评级，不会取代评级。如果评级是买入、评分却只有 40，报告就必须把理由讲清楚。

## 方法筛选

快照上还会跑八个"通过 / 不通过"的方法筛选，引用编号为 `lens:<id>`：
- 深度价值
- 高质量复利
- 合理价格成长
- 长期成长
- 趋势与动量
- 股东回报收益率
- 资产负债表风险排查
- 逆向反转

有数据的检查项不够时，该筛选记为 `out_of_scope`（不适用）。

## 局限

- 反向 DCF 固定使用 9% 折现率和 2.5% 永续增长率。它用来衡量市场预期，不是目标价。
- 免 Key 快照只有美股的财报数据。其他市场由研究台去读当地公告，"价格隐含的增长"在这些市场不适用。
- 触及概率没有考虑漂移、跳空和财报后的跳变。只能当作大致的概率，不是预测。
- 证据权重是经验规则。规则全部公开在这里，你可以不同意。
